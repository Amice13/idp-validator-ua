# Перевірка даних "Зимової допомоги"

Це додаток для швидкої автоматичної перевірки даних осіб, які подали заявку
на отримання гуманітарної допомоги населенню протягом опалювального сезону 
2026/27.

## Функції

Додаток містить шаблон для збирання даних у форматі Excel із налаштованим
переліком автоматизованих перевірок, а також можливість завантаження даних
і отримання швидкої перевірки їх якості.

## Валідація даних

Додаток проводить наступні перевірки:

* Найменування виконавчого органу
    * Перевірки наявності коду ЄДРПОУ юридичної особи
    * Перевірка валідності коду ЄДРПОУ за контрольною сумою
* РНОКПП голови домогосподарства
    * Перевірка наявності номера в переліку номерів членів домогосподарства
    * Перевірка валідності РНОКПП за контрольною сумою
    * Підсвітлення поля, якщо воно містить номер паспорта
* Вразливі категорії осіб
    * Перевіряє наявність виключно цифр та ком
    * Перевіряє діапазон цифр
* Прізвище
    * Перевірка на наявність в полі виключно кириличних символів, дефісу та апосторофу (за єдиним стилем)
    * Не має містити російські літери
* Ім'я
    * Перевірка на наявність в полі виключно кириличних символів, дефісу та апосторофу (за єдиним стилем)
    * Не має містити російські літери
* По батькові (за наявності)
    * Перевірка на наявність в полі виключно кириличних символів, дефісу та апосторофу (за єдиним стилем)
    * Не має містити російські літери
    * Має закінуватися на "[иі]ч", "[иії][вч]на", "Огли", "Кизи"
* Стать (чоловіча/жіноча)
    * Перевірка значення за словником
    * Перевірка на значення, закодоване в РНОКПП
    * Перевірка на значення за іменем по батькові
* Дата народження
    * Перевірка значення на відповідність патерну DD.MM.YYYY
    * Значення дати має бути не пізніше поточного дня
    * Значення дати має бути не більше 120 років назад
    * Для голови домогосподарства дата має бути не пізніше ніж за 18 років до поточного дня
    * Перевірка на відповідність дати, закодованої в РНОКПП
* Адреса - область
    * Перевірка значення за словником
* Адреса - район
    * Перевірка значення за словником
* Адреса - територіальна громада
    * Перевірка значення за словником
* Адреса - населений пункт
    * Перевірка значення за словником
    * Перевірка ієрархії повної адреси
* Адреса - вулиця
    * Перевірка відсутності латинських літер окрім тих, що позначають римські цифри (при нявності останніх надається попередження)
    * Перевірка наявності типу вулиці за визначеним словником (вул., пл., просп., тощо)
* Адреса - будинок
    * Довжина поля не більше 5 символів
    * Не має містити літер латинкою
* Адреса - квартира
    * Довжина поля не більше 5 символів
    * Попередження, якщо поле містить літеру
* Реєстраційний номер облікової картки платника податків
    * Перевірка наявності номера в переліку номерів членів домогосподарства
    * Перевірка валідності РНОКПП за контрольною сумою
    * Підсвітлення поля, якщо воно містить номер паспорта
* найменування документа
    * Перевірка за значенням зі словника
* серія (за наявності) та номер
    * Перевірка на відповідність паттернам для основних типів документів
* Довідка про взяття на облік ВПО - дата
    * Перевірка дати (аналогічна зазначеній вище)
    * Дата видачи свідоцтва має бути не раншіе 2014 року
* Довідка про взяття на облік ВПО - номер
    * Перевірка на відповідність паттерну
* Банківські реквізити (IBAN) одержувача грошової допомоги
    * Перевірка валідності IBAN
    * Перевірка на діючий банк на території України
Номер мобільного телефону
    * Перевірка на відповідність паттерну
    * Перевірка на наявність відповідного мобільного оператора

Додаткові перевірки

* Кілька домогосподарств за єдиною адресою
* Унікальність усіх документів, що посвідчують особу
* Унікальність усіх телефонних номерів
* Унікальність усіх IBAN
* Кількість осіб за однією адресою не має перевищувати 10 осіб
* Кількість осіб в одному домогосподарстві не має перевищувати 10 осіб
